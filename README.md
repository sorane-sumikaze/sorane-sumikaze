# 宙音 / Sorane

Webエンジニア。東京都在住。

各プロダクトは壊れにくい設計を起点に考え、安易なレガシー化の阻止を大切にします。
口頭で共有されているだけの手順に信用を置かず、曖昧なまま放置されがちな設計意図と運用方針の明文化を徹底しています。
